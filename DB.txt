[ 데이터베이스 ] : 여러 사람이나 여러 프로그램이 공유하려 사용할 수 있도록 데이터 집합
    - 데이터베이스 서버 : MYSQL, 요청에 따라 데이터 처리하고 응답하는 프로그램
    - 특징 : 실시간 접근, 동시 공유, 데이터 참조, 지속적인 변화 ( CRUD )
    - 종류:  1) 관계형 데이터베이스 : 표 
             2) NOSQL

[ SQL ] : 관계형 데이터베이스 데이터를 조작/제어하기 위한 표준 언어
    - DDL 데이터 정의어 : 데이터베이스 or 테이블을 정의/변경할 때 사용 -> create drop alter truncate rename 
    - DML 데이터 조작어 : 테이블 내 데이터들을 조작할 때 사용 -> select insert update delete
    - DCL 데이터 제어어 : 데이터베이스 접근권한 / 계정관리  -> grant revoke
    - TCL 트랜잭션 제어어 : DML 실행 결과를 취소하거나 적용함

[ 메타데이터 ]
    show databases;
    user 데이터베이스명;
    describe 테이블명; 

[ DDL ]
    DROP:
        drop database if exists 데이터베이스명;
        drop table if exists 테이블명;
    CREATE:
        create database if exists 데이터베이스명;
        create table 테이블명( 필드명 타입 제약조건 );
    ALTER:
        alter table 테이블명 add 필드명 새로운타입;
        alter table 테이블명 modify 필드명 새로운타입;
        alter table 테이블명 change 기존필드명 새로운필드명 새로운타입;
    RENAME:
        rename table 테이블명 to 새로운테이블명;
    TRUNCATE:
        truncate table 초기화할테이블이름;

[ 타입 ]
    정수 : tinyint, smallint, mediumint, bigint
    * unsigned : 부호가 없는 자료 -> 음수가 사라짐 -> -128~127 -> 258

    실수 : float, double, decimal(실수를 문자열로 처리, 문자열타입임, 오차 줄임)
    날짜 : DATE
    시간: TIME 
    날짜+시간: DATETIME
    문자열 : CHAR(N), VARCHAR(N), TEXT, LONGTEXT
                * char(3) : 고정 길이 3글자 → [유], [재], []
                * VARCHAR(3) : 가변 길이 3글자 → [사][과]
                * longtext : 대용량

    논리 : boolean(tinyint)


[ 제약 조건 ]
    not null                                            : insert 할 때, null 값을 포함하지 않겠다 (null값 등록 불가)
    unique                                              : 값이 중복일 때 레코드 등록 허용 안함
    default 초기값                                      : 레코드 등록 시 값 생략하면 기본값으로 등록
    auto_increment                                      : 레코드 등록 시 자동 증가 번호 대입, 기본 키(PK)에서만 사용 가능
    primary key(필드명)                                 : 해당 필드명을 기본키로 설정
    foreign key(필드명) references 상위 테이블명(필드명): 외래 키 설정 

[ 참조 옵션 ]
    1. on delete / update cascade;                      : PK 삭제시 FK 레코드 같이 삭제됨
    2. on delete / update restrict;                     : 참조중인 FK가 있을 경우 PK 삭제/변경 불가 (기본값)
    3. on delete / update set null;                     : PK 삭제시 FK값은 null


[ DML ]
    1. insert into 테이블명( 필드명, 필드명 ) values( 값1, 값2 );
        - insert into 테이블명 values (값1, 값2, 값3);      -> 모든 필드에 값 대입 시 필드명 생략 가능
        - insert into 테이블명( 필드명) values(값),(값);
    
    2. select 필드명 from 테이블명 where 조건
        - select * from 테이블명 : 테이블 내 모든 필드의 레코드 조회
    
    3. update 테이블 set 필드명 = 수정할값 where 조건절;

    4. delete from 테이블명 where 조건

[ 연산자 ]
    1. as 별칭, 필드명 as 별칭, 테이블명 as 별칭        : 별칭(복잡한 필드명/테이블명 간단하게 별명 만들어서 SQL 내에서만 사용) 지정     * 주의: as 생략 가능
    2. distinct                                         : 조회결과 (필드값의)중복 제거 
    3. 산술연산자                                       : + - / * div(몫) mod(나머지)
    4. 비교연산자                                       : = != > < <= >=
    5. 논리연산자                                       : and, or, not, between 시작값 and 끝값, *in( 값1, 값2, 값3)
    6. null 연산자                                      
        필드명 = null < 불가능 >    필드명 != null < 불가능 >
        필드명 is null              필드명 is not null

    7. 문자열패턴: 필드명 like "문자열패턴"
        % 모든 문자 대응        김& -> 김으로 시작하는 n글자
        _ 개수만큼 문자 대응    김_ -> 김으로 시작하는 2글자
