[ 데이터베이스 ] : 여러 사람이나 여러 프로그램이 공유하려 사용할 수 있도록 데이터 집합
    - 데이터베이스 서버 : MYSQL, 요청에 따라 데이터 처리하고 응답하는 프로그램
    - 특징 : 실시간 접근, 동시 공유, 데이터 참조, 지속적인 변화 ( CRUD )
    - 종류:  1) 관계형 데이터베이스 : 표 
             2) NOSQL

[ SQL ] : 관계형 데이터베이스 데이터를 조작/제어하기 위한 표준 언어
    - DDL 데이터 정의어 : 데이터베이스 or 테이블을 정의/변경할 때 사용 -> create drop alter truncate rename 
    - DML 데이터 조작어 : 테이블 내 데이터들을 조작할 때 사용 -> select insert update delete
    - DCL 데이터 제어어 : 데이터베이스 접근권한 / 계정관리  -> grant revoke
    - TCL 트랜잭션 제어어 : DML 실행 결과를 취소하거나 적용함
