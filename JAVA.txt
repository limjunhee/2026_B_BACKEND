
[ 자바 실행순서 ]
1. src/.java에서 java 코드 작성함
    -> bin/.class에서 렌더링
2. 빌드(build) : run java 실행
3. bin폴더 내 .class 확장자 파일 자동 생성

[ 주석 ]
JS랑 동일
// <- 한줄
/**/ <- 여러줄

[ 용어 ]
1. package : 클래스 담은 폴더명
2. class : 자바에서 컴파일 하는 최소 단위 *클래스{} 안에서 코드 작성해야 함*
3. main함수 : 자바에서 코드 실행하는 흐름 = 스레드 제공
4. ; : 코드 문장 마침표시

[ 자료 ] : 데이터
1. 리터럴
2. 자료 타입
    [1] boolean -> true / false ,           1byte
    [2] char -> 'a' / 'A' 문자 하나 저장,   2byte
    [3] byte -> -128 ~ 128                  1byte 
    [4] short -> -+3만정도                  2byte
    [5] int -> -+21억정도                   4byte       * 정수 리터럴 기본 타입
    [6] long -> -+21억 이상                 8byte       * 뒤에 L/l를 붙임
    [7] float -> 소수점 8자리,              4byte       * 뒤에 F/f를 붙임
    [8] double -> 소수점 17자리             8byte       * 실수 리터럴 기본 타입
    [9] String -> 문자열 객체(배열)         n*2byte


[ 출력함수 ]
    1. System.out.print(  )                 출력
    2. System.out.println(  )               출력 이후 줄바꿈
    3. System.out.printf("형식 문자", 자료)

    * 이스케이프 문자 : \n \t, \', \", \\ 

    * 형식문자: %d 정수 / %s 문자열 / %c문자 / %f실수 / %자릿수s / %0자릿수f / %전체자릿수.소수점자릿수f

[ 입력함수 ] : 자바에서 제공되는 다양한 입력 방식
    1. 입력 객체 생성(클래스마다 한 번씩) 
        import java.util.Scanner;
        Scanner scan = new Scanner( System.in );
    2. 입력 객체를 통한 입력 함수( nextXXX() ->  타입에 주의할 것, 여러개의 nextXXX()를 사용할 땐 엔터 기준으로 입력이 구분된다. )
        타입 변수명 = scan.nextXXX();

        ※.nextLine() : 개행(\n)을 사용하기 때문에 앞에 다른 .nextXXX() 존재했을 때 앞전 개행 포함함
            예시 -> .nextInt() ~ .nextLine() : nextInt()에서 3 입력 후 엔터 치면 3 반환되고 엔터를 넣는다.
            해결 방안 -> 의미 없는 .nextLine()을 하나 더 넣어서 멘터를 받아들이게 함


[ 형변환 ]
    * 다형성 - 하나의 자료/값이 다양한 형태(타입)를 가진 성질 *본래의 자료 유지
    1) 자동 타입 변환: byte -> short -> int -> long -> float -> double * 연산 결과
    2) 강제 타입 변환: double -> float -> long -> int -> short -> byte      * (반환할타입명) 자료/값
    
[ 연산자 ]
    1. 산술연산자: + - / % *
    2. 비교연산자: < > <= >= == !=
    3. 논리연산자: & ||
    4. 증감연산자: 변수명++ 변수명-- ++변수명 --변수명
    5. 대입연산자:  = += -= *= /= %=
    6. 삼항연산자: 조건식 ? true값 : false값
    7. 연결연산자: +

    * 문자열비교함수:
        "유재석" == "유재석" [가능]
        
        new String("유재석") == "유재석" [불가능]
        
        문자열A.equals( 문자열B ) == true [가능]


[ 조건문 ]
    1. if(조건) { 실행문 };
    
    2. if(조건) {
        실행문;
        실행문
    }

    3. if(조건){ 실행문 } else if( 조건 ) { 실행문 } else if( 조건 ) { 실행문 } else { 실행문 };
    4. if ( 조건 ) { 실행문 };
    5. switch( 자료 ) {
        case 자료1:
            실행문;
            break;
        case 자료2:
            실행문;
            break;
        default:
            실행문
            break
    } // break가 없으면 자료1일경우 아래에 있는 실행문 전부 실행

[ 반복문 ]
    1. for(초기값; 조건식; 증감식){ 실행문; }
    * break; continue;
    2. while( 조건식 ){ 증감식; }
    3. [향상된 for문]
        for(타입 변수명 : 배열){  }


[ 배열 ] *동일한 타입의 여러 자료만을 순차적으로 담는* 하나의 배열 타입    
    1. 선언법
    - 타입[ ] 변수명 = new 타입[개수]
    - 타입[ ] 변수명 = { 값1, 값2, 값3 }

    2. 특징
        [1] 동일한 타입만 담는다. → int배열은 int요소값만 담음
        [2] 정적(고정됨)인 길이를 가진다. (배열 길이의 기본값)
        [3] 요소 초기값이 자동으로 할당된다. 
            *** ( 정수 초기값 = 0, 실수 초기값 = 0.0, 논리 초기값 = false, 객체 초기값 = null )

    3. 호출
        [1] 변수명                                  : 변수명 그 자체를 콘솔에 출력하면 배열의 주소값 반환(식별용도?)
        [2] Arrays.toString(배열변수)               : 배열의 요소들을 반환
        [3] 배열변수[index]                         : 배열 내 요소들이 저장된 순서 번호인 인덱스 -> 인덱스로 요소 값 반환

    4. 요소값 수정 : 배열변수[인덱스] = 새로운 값
        * 단, 요소 삭제와 추가 없음 (메소드가 없다.) → 라이브러리 사용


[ 객체 ]
    1. 정의 : 상태(멤버변수/필드/속성)와 행위(메소드/함수)를 정의함
    2. 클래스 : 상태와 행위 코드로 설계(설계도)
        용도 -> 설계, 실행(main 함수 갖는)
    3. 인스턴스 : 특정 클래스 생성(new)한 객체(실체)
    4. 사용법
        1) 클래스 생성
            class 클래스명 { 타입 멤버변수명; 생성자; 메소드; }
            * 멤버 변수 초기값은 없어도 됨

        2) 인스턴스 생성
            - new 생성자명( );      * new 1개당 인스턴스 1개 생성(== 메모리 주소값을 생성)
            - 타입 변수명 = new 생성자명( );

        3) 인스턴스 참조
            - 객체변수명.멤버변수명;            *(접근/도트) . 연산자 : 변수가 갖는 객체의 주소로 이동한다는 뜻.(포인터)            *null. <- 없음
            - null : 변수가 null이면 이동할 주소가 없다.

            // JS 객체의 경우
            클래스가 있는 객체 / 없는 객체가 존재함


        *) 객체는 변수가 참조하지 않으면 자동으로 사라짐 (Garbage Collector)
        
    5. 클래스 작성 시 주의점
        동일한 패키지(폴더) 내 동일한 클래스명 중복 불가능.
        src (개발자코드 .java)--------> bin(컴파일/번역코드)
        클래스 이름 첫 글자는 대문자 시작
        클래스 1개 당 .java 1개 관리 권장 (* 디자인 패턴 *)


* 지역변수 : if문/for문/함수 내에서 선언된 변수
* 멤버변수 : 클래스(설계도) 안에서 선언되고 new 인스턴스(실체) 안에서 생성된 객체 내 변수
                this : 해당 생성자/메소드를 호출한 객체(인스턴스)를 가리킴
* 매개변수 : 생성자/메소드 호출하면서 인수값들을 저장하는 변수

[생성자]
    - 인스턴스(객체) 생성할 때 초기화 담당
        new 생성자명( );
    - 사용법
        1. 클래스 내부 선언
        2. 클래스명 동일
        3. 반환 타입 없음 ( 주소값 반환 )
        4. 오버로딩 지원( 동일한 이름의 서로 다른 매개변수의 개수/타입 )
    
    - 사용 목적
        객체 생성 시 초기화, 협업간의 규칙 / 유효성 검사

    - 주의점
        정의한 클래스 내 생성자가 1개도 없다면 기본 생성자를 자동으로 생성함

    - this 키워드
        멤버변수와 매개변수명이 동일한 경우 멤버 변수를 가리킴

        클래스 내부에서 오른쪽 클릭 -> 소스 작업 -> constructor -> 멤버변수 체크 -> [확인]

[ 메소드 / 함수 ]
    1. 자바 클래스 내부 선언
    2. 목적 : 코드의 재사용, 인수에 따른 결과물 반환
    3. 선언
        접근제한자 반환타입 메소드명 ( 타입 매개변수, 타입 매개변수, ... ){
            실행문;
            return 반환값;
        }
        - void : 반환할 값의 타입 없으면 void로 지정
        - 매개변수 : 메소드 호출시 전달되는 인수/인자 값 저장하는 변수

    4. 호출
        1) 서로 다른 클래스의 경우: 객체변수명.메소드명( );
        2) 같은 클래스 경우: this.메소드명( );
        3) 정적 메소드인 경우: 클래스명.메소드명( );

    5. 지역변수: if / for / 메소드{ } 내 매개변수 or 선언된 변수
                 선언된 구역 밖에서 사용될 수 없다.

[ 접근제한자 ]
    1. 서로 다른 클래스간 접근 여부
    2. 종류
        public      : 프로젝트 내 어디서든 호출 가능
        private     : 현재 클래스 내 호출과 사용 가능
        (default)   : 같은 패키지 내 호출/사용
        protected   : 같은 패키지내 호출/사용, 단) 상속 관계 예외
    3. 사용처
        클래스, 변수, 생성자, 메소드 등등
        * 관례적으로 멤버변수는 *private* 한다.

[ 주요 키워드 ]
    1. static: 인스턴스 없이 클래스내 변수와 (정적)메소드 사용, 멤버변수 또는 메소드에서 사용
                * 프로그램 시작 시 메모리 할당, 종료 시 메모리 삭제 *
    2. final: 초기화 이후 수정 불가, *초기화 필수*, 멤버변수 또는 메소드 사용
                * public static final 상수명 = 초기값, 상수(const)
    3. setter and getter: 멤버변수가 private인 경우 간접 접근 제공하는 함수
        - set 멤버변수명 (  ) : 저장, get 멤버변수명( ) : 호출
        - 클래스내 오른쪽클릭 -> 소스 작업 -> setter and getter
    4. toString() : 인스턴스 호출시 주소값 대신에 문자열 반환하는 메소드
    5. 패키지 해당 클래스가 위치한 경로/위치
    6. import: 다른 클래스 호출한 경우 .java 파일 상단에 호출한 클래스의 패키지 / 경로 표시
                * 단, java.lang 패키지는 제외( System, String, Math )한 다른 클래스의 경우를 말한다.


[ MVC 패턴 ]
    1. 정의 : 소프트웨어 개발에서 사용되는 디자인 패턴으로, 세 가지 주요 역할 분리하여 코드의 모듈화(조각)
    2. 목적 : 협업간의 코드와 파일들을 mvc패턴 따라 구성하여 효율성 높인다.
    3. 장점 : 유지보수, 모듈화, 단일책임기능(SRP : 단일 책임 원칙) 등
